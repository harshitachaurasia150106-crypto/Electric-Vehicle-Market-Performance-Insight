# Electric Vehicle Market Performance & Insights ⚡

An interactive data visualization project exploring electric vehicle market performance, trends, and adoption metrics using Tableau Public and Flask.

## 📊 Project Overview

This project analyzes electric vehicle market data and presents actionable insights through interactive Tableau dashboards embedded in a modern Flask web application.

## ✨ Features

- Interactive Tableau Dashboards & Data Stories
- Comprehensive Market Trend Analysis
- Responsive Flask Web Interface
- Clean & Modern Dark UI Design

## 🛠️ Technologies Used

- Python / Flask
- Tableau Public
- HTML5 / CSS3
- Git & GitHub

## 🚀 Run Locally

1. Clone this repository:
   git clone [https://github.com/harshitachaurasia150106-crypto/Electric-Vehicle-Market-Performance-Insight.git]

2.Navigate to the project directory:

cd Electric-Vehicle-Market-Performance-Insight

3.Install dependencies:

pip install -r requirements.txt

4.Run the flask application:

python app.py

5.Open http://127.0.0.1:5000 in your browser.

Live demo--https://evmarketperformanceandinsight.netlify.app/

About the Project

Turning raw EV market data into clear, decision-ready insight.

This project analyses electric vehicle market performance and presents the findings through Tableau Public visualisations embedded in a Flask web application. Use the dashboard to explore the data yourself, or follow the story for a curated walkthrough of the main takeaways.
